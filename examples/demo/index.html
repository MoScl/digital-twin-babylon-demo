使用说明 / 这是什么
本页演示一套统一命令入口的数字孪生 API 层（Babylon.js 适配）。 所有能力都通过同一行代码调用：
twin.execute(command, params)
并返回统一信封 { code, message, data, requestId, elapsed }。
  • 左侧按钮：每个对应一个命令，鼠标悬停可见真实命令名与参数
  • 右侧日志：每次调用的命令名、返回码与耗时（绿=成功 / 红=错误 / 紫=事件 / 蓝=命令）
  • 场景交互：左键拖拽旋转 · 滚轮缩放 · 右键平移 · 点击建筑触发实体回调
  • 一键演示：按顺序自动跑一遍核心能力，适合快速了解
